# Keyboard Saver

키보드를 청소하는 동안, 키보드 입력을 잠깐 막아주는 무료 앱이에요.

## 앱 안내

열어둔 앱을 종료하지 않고 키보드를 편하게 닦아보세요. 청소 중에도 마우스와 트랙패드는 그대로 사용할 수 있어요.

- **Mac과 Windows에서 사용할 수 있어요.**
- **버튼을 눌러 시작하고, 마우스로 끝내요.**
- **키보드 입력 내용을 저장하거나 전송하지 않아요.**

## 다운로드 방법

**[다운로드 페이지 열기](https://github.com/safience-mia/keyboard-saver/releases)**

현재 첫 버전을 공개할 준비를 하고 있어요. 공개 후 위 페이지에서 설치 파일을 받을 수 있어요.

1. 다운로드 페이지에서 버전 아래의 **Assets(첨부 파일)**를 펼쳐요.
2. 내 컴퓨터에 맞는 ZIP 파일을 받아요.

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Mac · macOS 12 이상 · Apple Silicon/Intel | 이름이 `macos-universal.zip`으로 끝나는 파일 |
| Windows 10/11 · x64 | 이름이 `windows-x64.zip`으로 끝나는 파일 |

**Mac:** 압축을 풀고 **Keyboard Saver.app**을 **응용 프로그램** 폴더로 옮긴 뒤 실행해요.

**Windows:** ZIP 파일을 우클릭해 **모두 압축 풀기**를 누르고, 폴더 안의 **keyboard_saver.exe**를 실행해요. 함께 들어 있는 파일과 폴더도 그대로 보관해주세요.

현재 테스트 버전은 실행할 때 보안 경고가 나타날 수 있어요. Mac에서 개발자를 확인할 수 없다는 경고로 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 확인해주세요. [Apple의 실행 안내](https://support.apple.com/ko-kr/102445)도 참고할 수 있어요.

## 사용법

Mac에서는 처음 한 번, 앱의 **권한 설정 열기**를 눌러 **손쉬운 사용**에서 Keyboard Saver를 허용해주세요. 앱으로 돌아와 **권한과 상태 다시 확인**을 누르면 준비가 끝나요.

1. 키보드에서 손을 떼고 **청소 시작**을 눌러요.
2. 키보드를 청소해요. 마우스와 트랙패드는 계속 사용할 수 있어요.
3. 청소가 끝나면 키보드에서 손을 뗀 뒤, 마우스로 **청소 끝내기**를 눌러요.

**청소 모드는 자동으로 끝나지 않아요. 마우스로 종료해주세요.**

전원·Touch ID·Ctrl+Alt+Delete와 일부 기기의 밝기 키는 차단되지 않을 수 있어요.

앱이 반응하지 않으면 마우스로 종료할 수 있어요.

- **Mac:** 다른 앱을 클릭한 뒤 ** → 강제 종료 → Keyboard Saver**를 선택해요.
- **Windows:** **시작 버튼 우클릭 → 작업 관리자**에서 Keyboard Saver를 찾아 **작업 끝내기**를 눌러요.

문제가 있거나 의견을 전하고 싶다면 [Issues에 남겨주세요](https://github.com/safience-mia/keyboard-saver/issues).
