Keyboard Saver {{version}} — Windows용 무료 테스트 버전

지원: Windows 10/11 / {{architecture}}

실행
1. ZIP 파일을 우클릭하고 '모두 압축 풀기'를 선택합니다.
2. 압축을 푼 폴더에서 keyboard_saver.exe를 실행합니다.
3. EXE 옆의 DLL과 data 폴더를 함께 보관하세요. EXE만 따로 옮기면 실행되지 않습니다.
4. 필요한 Visual C++ 런타임 DLL은 함께 들어 있습니다.
5. 이 테스트 버전에는 배포용 코드 서명이 없어 Windows 보안 경고가 나타날 수 있습니다.

사용
- 키보드에서 손을 떼고 '청소 시작'을 누릅니다.
- 청소 모드에는 자동 종료 시간이 없습니다. 마우스와 트랙패드는 계속 사용할 수 있습니다.
- 청소가 끝나면 키보드에서 손을 뗀 뒤 마우스로 '청소 끝내기'를 누릅니다.
- 앱이 반응하지 않으면 시작 버튼을 우클릭해 작업 관리자를 열고 Keyboard Saver를 종료합니다.

참고
- 입력 내용이나 입력 이력을 저장·전송하지 않습니다.
- Ctrl+Alt+Delete, UAC·보안 데스크톱과 제조사별 밝기 키는 차단을 보장하지 않습니다.
- 자동 업데이트는 지원하지 않습니다. 새 버전은 별도 폴더에 압축을 풀어 사용하세요.
- 삭제하려면 앱을 종료하고 압축을 푼 폴더를 삭제하세요.
