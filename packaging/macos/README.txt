Keyboard Saver {{version}} — Mac용 무료 테스트 버전

지원: macOS {{minimum_macos}} 이상 / {{architecture}}
universal 파일은 Apple Silicon과 Intel Mac에서 모두 실행할 수 있습니다.

설치
1. ZIP 압축을 풀고 Keyboard Saver.app을 응용 프로그램 폴더로 옮깁니다.
2. 응용 프로그램 폴더에서 Keyboard Saver를 엽니다.
3. 이 테스트 버전은 Apple 공증을 받지 않았습니다. 개발자를 확인할 수 없다는
   경고로 실행이 차단되면, 시스템 설정 → 개인정보 보호 및 보안에서 방금
   차단된 Keyboard Saver 항목의 '확인 없이 열기'를 확인하세요.
   https://support.apple.com/ko-kr/102445
4. 앱에서 '권한 설정 열기'를 누르고 시스템 설정 → 개인정보 보호 및 보안 →
   손쉬운 사용에서 Keyboard Saver를 허용합니다.
5. 앱으로 돌아와 '권한과 상태 다시 확인'을 누릅니다.

사용
- 키보드에서 손을 떼고 '청소 시작'을 누릅니다.
- 청소 모드에는 자동 종료 시간이 없습니다. 마우스와 트랙패드는 계속 사용할 수 있습니다.
- 청소가 끝나면 키보드에서 손을 뗀 뒤 마우스로 '청소 끝내기'를 누릅니다.
- 앱이 반응하지 않으면 다른 앱을 클릭한 뒤  → 강제 종료에서 Keyboard Saver를 종료합니다.

참고
- 입력 내용이나 입력 이력을 저장·전송하지 않습니다.
- 전원·Touch ID, 기기 자체에서 처리하는 키와 보안 입력은 차단을 보장하지 않습니다.
- 업데이트 뒤 권한이 인식되지 않으면 앱의 '허용했는데도 안 되나요?' 안내를 따르세요.
- 자동 업데이트는 지원하지 않습니다. 새 버전은 다운로드해 기존 앱을 교체하세요.
